# Worker Cancellation Evidence

## Implementation
- Worker agent now uses supervisor.pick_least_loaded() to get a tracked worker handle.
- On lease loss (tokio::select!), calls worker.kill().await to terminate child process.
- kill() sends SIGKILL and reaps the process.

## Gap
- Forced termination (SIGKILL) is used immediately; no graceful shutdown period.
- Browser process may not clean up gracefully.
