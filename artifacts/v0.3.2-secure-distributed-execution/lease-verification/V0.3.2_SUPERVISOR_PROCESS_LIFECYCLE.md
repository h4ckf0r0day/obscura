# Supervisor Process Lifecycle

## Current Behavior
- Supervisor spawns child process with kill_on_drop(true).
- Graceful shutdown sends shutdown command, waits grace period, then kills.
- Child process is reaped on drop.
- On lease loss, select! drops the dispatch future; child process continues (not killed).

## Gap
- No explicit kill on lease loss. Child process runs to completion; result is rejected by fencing token.
