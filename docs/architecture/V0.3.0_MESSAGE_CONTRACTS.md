# v0.3.0 Message Contracts (NATS JetStream)

## Streams

- `OBScura_JOBS`: subjects `obscura.jobs.*`
- `OBScura_WORKERS`: subjects `obscura.workers.*`
- `OBScura_EVENTS`: subjects `obscura.events.*`

## Subject naming

- `obscura.jobs.submit`
- `obscura.jobs.dispatch`
- `obscura.jobs.completed`
- `obscura.jobs.failed`
- `obscura.jobs.cancelled`
- `obscura.workers.register`
- `obscura.workers.heartbeat`
- `obscura.workers.drain`
- `obscura.events.lease.expired`

## Consumer configuration

- Durable consumers per scheduler instance.
- Ack explicit, manual ack.
- MaxDeliver: 5 (configurable).
- AckWait: 30s.
- Backoff: exponential 1s, 5s, 15s, 30s, 60s.
- Dead-letter stream: `OBScura_DLQ`.

## Message envelope

```json
{
  "version": "1.0",
  "message_id": "uuid",
  "idempotency_key": "string",
  "tenant_id": "uuid",
  "traceparent": "string",
  "payload": { ... }
}
```

## Payloads

JobDispatch:
```json
{ "job_id": "uuid", "worker_id": "uuid", "lease_id": "uuid", "fencing_token": 42, "url": "...", "operation": "navigate" }
```

WorkerHeartbeat:
```json
{ "worker_id": "uuid", "status": "healthy", "active_jobs": 2, "capacity": 8, "metrics": {} }
```

JobCompleted:
```json
{ "job_id": "uuid", "lease_id": "uuid", "fencing_token": 42, "result": {} }
```

## At-least-once delivery
Consumers must be idempotent. Use idempotency_key + PostgreSQL state check.

## Outbox
Control plane writes outbox_events in same transaction as state change. Publisher polls unpublished rows and publishes to NATS. On success sets published_at. On failure increments attempts; retries with backoff.
