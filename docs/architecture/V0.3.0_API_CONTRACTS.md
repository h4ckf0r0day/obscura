# v0.3.0 API Contracts (versioned, /v1)

## SubmitJob
POST /v1/jobs
Request:
```json
{ "url": "https://...", "operation": "snapshot", "idempotency_key": "optional", "timeout_ms": 30000 }
```
Response 201:
```json
{ "job_id": "uuid", "status": "pending" }
```

## GetJob
GET /v1/jobs/{job_id} -> { job_id, status, result, error, timestamps }

## ListJobs
GET /v1/jobs?status=&limit=&cursor= -> { items, next_cursor }

## CancelJob
POST /v1/jobs/{job_id}/cancel -> { status: "cancelled" }

## ListWorkers
GET /v1/workers -> { items: [{ worker_id, status, capacity, active_jobs, last_heartbeat }] }

## GetWorker
GET /v1/workers/{worker_id}

## WorkerHealth
GET /v1/workers/{worker_id}/health

## GetSession
GET /v1/sessions/{session_id}

## ControlPlaneHealth
GET /health -> { status, version, uptime }

## Readiness
GET /ready -> { ready: bool, checks: {} }

## Error format
```json
{ "error": { "code": "JOB_NOT_FOUND", "message": "..." } }
```

## Idempotency
SubmitJob accepts idempotency_key; duplicate returns existing job.

## Compatibility
MCP API and SDKs remain backward compatible. Migration notes for any breaking change.
