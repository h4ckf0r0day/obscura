- Fencing token comparison, lease expiry logic, idempotency checks.

- Outbox publication and redelivery.

- Use controllable clock abstraction for lease tests.

## E2E
- Browser job end-to-end against supervised workers.

## Deployment
- Docker Compose with PostgreSQL + NATS + control plane + worker + Prometheus.

## Security
- Auth failure, tenant boundary, SSRF.
