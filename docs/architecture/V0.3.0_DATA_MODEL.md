# v0.3.0 Data Model (PostgreSQL)

## Principles
- PostgreSQL is authoritative.
- All tenant-scoped tables have `tenant_id`.
- Use UUID primary keys.
- Fencing tokens are monotonic per job (bigint).
- Outbox ensures DB commit and message publication consistency.

## Tables

### tenants
- tenant_id UUID PK
- name TEXT UNIQUE
- created_at TIMESTAMPTZ

### workers
- worker_id UUID PK
- tenant_id UUID FK tenants (nullable for global workers)
- status TEXT (registering, healthy, degraded, draining, terminated)
- capabilities JSONB
- capacity INT
- last_heartbeat_at TIMESTAMPTZ
- created_at, updated_at

### jobs
- job_id UUID PK
- tenant_id UUID FK tenants
- status TEXT (pending, queued, assigned, running, completed, failed, cancelled, dead_letter)
- url TEXT
- operation TEXT
- payload JSONB
- idempotency_key TEXT UNIQUE (tenant_id, idempotency_key)
- attempt_count INT
- max_attempts INT
- fencing_token BIGINT (current)
- lease_id UUID
- worker_id UUID FK workers
- created_at, updated_at, started_at, completed_at

Indexes: (tenant_id, status), (status, created_at), idempotency unique.

### job_attempts
- attempt_id UUID PK
- job_id UUID FK jobs
- worker_id UUID FK workers
- fencing_token BIGINT
- status TEXT
- started_at, finished_at
- error_code TEXT, error_message TEXT

### sessions (distributed)
- session_id UUID PK
- tenant_id UUID FK tenants
- job_id UUID FK jobs
- worker_id UUID FK workers
- status TEXT
- created_at, last_active_at

### session_leases
- lease_id UUID PK
- session_id UUID FK sessions
- worker_id UUID FK workers
- fencing_token BIGINT
- expires_at TIMESTAMPTZ
- renewed_at TIMESTAMPTZ

### job_events
- event_id BIGSERIAL PK
- job_id UUID FK jobs
- event_type TEXT
- payload JSONB
- created_at TIMESTAMPTZ

### audit_events
- audit_id BIGSERIAL PK
- tenant_id UUID
- actor TEXT
- action TEXT
- resource_type TEXT
- resource_id TEXT
- created_at TIMESTAMPTZ

### outbox_events
- outbox_id BIGSERIAL PK
- aggregate_type TEXT
- aggregate_id TEXT
- event_type TEXT
- payload JSONB
- created_at TIMESTAMPTZ
- published_at TIMESTAMPTZ NULL
- attempts INT DEFAULT 0

Index: (published_at NULL, created_at).

### worker_heartbeats
- worker_id UUID FK workers
- heartbeat_at TIMESTAMPTZ
- metrics JSONB

## Transaction boundaries
- Job submission: jobs + outbox in one transaction.
- Lease acquisition: job + lease + fencing token in one transaction (SELECT FOR UPDATE).
- Completion: validate fencing token, update job + attempt in one transaction.

## Migrations
- Use versioned SQL migrations (sqlx or refinery). Forward-only with rollback scripts in dev.

## Retention
- job_events: 30 days.
- audit_events: 90 days.
- outbox published: 7 days then archive.

## Connection pooling
- PgPool with max_connections based on control plane replicas.
