# v0.3.0 Failure Model

| Failure | Required behavior |
|---|---|
| Worker crash | Heartbeat expiry; lease expires; job reclaimed; new worker executes (bounded retries) |
| Worker network partition | Lease expiry prevents stale writes; fencing token rejects late completion |
| NATS outage | Outbox retains pending; dispatch resumes on recovery; no durable success claimed |
| PostgreSQL outage | Fail safely; control plane returns 503; no state mutation |
| Duplicate message | Idempotency check; ack and skip or reject |
| Scheduler crash | Resume from persistent PostgreSQL + NATS durable consumer |
| Control-plane restart | Restore all state from PostgreSQL |
| Expired lease | Stale worker completion rejected at persistence boundary |
| Repeated job failure | Bounded retries then dead-letter |
| Tenant auth failure | Reject + audit event |
| Worker overload | Backpressure: scheduler skips workers at capacity; queue depth metric |
| Outbox publish failure | Retry with backoff; alert if backlog grows |

## Error classification
- Transient: network timeout, temporary DB lock -> retry.
- Permanent: invalid URL, SSRF block, bad script -> no retry, mark failed.
- Infrastructure: DB/NATS down -> pause dispatch, preserve state.
