# V0.3.2 Architecture Design

## Auth Model
- Principal struct with tenant_id, is_admin, is_worker.
- authorize_tenant(principal, tenant_id) enforces access.
- Auth params added to submit_job, get_job, list_jobs, cancel_job (Option<&Principal>).

## Lease/Fencing
- fencing_token_seq generates monotonic tokens.
- mark_dispatched allocates token, stores in jobs + job_attempts.
- complete_job/fail_job validate token transactionally.
- DispatchMessage carries fencing_token.

## Recovery
- Scheduler::reconcile() schedules pending jobs.

## Remaining
- Lease lifecycle not fully wired into worker agent.
- Auth not enforced at all call sites (optional param).
