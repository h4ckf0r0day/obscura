# V0.3.2 Lease Renewal & Ownership-Loss Implementation

## Baseline
Commit: 44f9c68

## Changes
- Worker agent acquires lease (30s TTL) before browser execution.
- Background renewal task renews every 5s.
- tokio::select! races browser execution against lease-loss signal.
- On lease loss: fail_job with LEASE_LOST, no success persisted, renewal task aborted.
- On completion/failure: renewal task aborted.

## Gap Identified
- Browser child process is not explicitly killed on lease loss (select! drops future but child continues).
- Lease expiry is not actively detected (renewal failure triggers loss, but expired lease is only detected on next renewal attempt).
